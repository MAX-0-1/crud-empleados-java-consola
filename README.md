# CRUD de Empleados en Java (Consola)

Ejercicio práctico en Java por consola para afinar la lógica de separación por capas (`Controller`, `Service`, `Repository`, `DTO`, `Mapper`) y el manejo de excepciones personalizadas antes de trabajar con Spring Boot.

## Qué practica este ejercicio
- Operaciones CRUD en memoria sobre empleados.
- Validación de datos de entrada y conversión segura de tipos (`ParametroParser`).
- Acumulación de errores de validación en una sola excepción (`ExcepcionesAcumuladas`) y captura centralizada (`ErrorHandler`).

## Ejecución
Compilar y ejecutar la clase principal `Ejercicio3.Main`.
